## What it does

`main.py` writes exactly one line of text to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(`/output/entry.txt` by default): the funniest excuse an AI agent could hand
its human for missing a deadline. Stdlib-only Python, fully deterministic —
every run produces the same bytes.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
